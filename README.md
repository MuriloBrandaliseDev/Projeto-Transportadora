# 🚛 Site para Transportadora  

Bem-vindo ao repositório do **Site para Transportadora**, um projeto desenvolvido para oferecer uma presença digital moderna e eficiente para empresas de logística.  

---

## 📌 Sobre o Projeto  

Este site foi desenvolvido com o objetivo de apresentar os serviços de uma transportadora de forma profissional, intuitiva e responsiva. Ele conta com uma interface amigável e interativa, proporcionando uma ótima experiência ao usuário.  

### 🔹 Principais Funcionalidades  
✅ **Design Responsivo** – O site se adapta a diferentes dispositivos (desktop, tablet e mobile).  
✅ **Seção de Serviços** – Apresentação dos principais serviços da transportadora.  
✅ **Formulário de Contato** – Permite que clientes entrem em contato facilmente.  
✅ **Animações e Interatividade** – Elementos dinâmicos para uma melhor experiência.  

---

## 🛠 Tecnologias Utilizadas  

- **HTML5** – Estrutura do site.  
- **CSS3** – Estilização e responsividade.  
- **JavaScript** – Interatividade e funcionalidades dinâmicas.
